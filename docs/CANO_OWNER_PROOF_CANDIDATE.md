# Transaction-bound owner proof (candidate only)

On an isolated PostgreSQL rehearsal database, an unsigned owner GUC change exposed two synthetic rows. A restrictive HMAC policy denied the same query. Eight tables and six allowed roles passed 81 signed/modified/forged read controls. No production policy or deployment is authorized by this document. The adapter mode defaults to off; required mode needs separate server-side role-specific random 32-byte keys, matching protected database key registry, and the tested verifier policy. Never use DB passwords as signing keys or commit keys. Provision via protected channels; rotate and test pooling, direct login, all writes, legacy owner keys, resolver, actual app auth and rollback before enabling. A compromised trusted app signing secret is outside this boundary. Existing database-only worker role must not receive signing keys. This PR contains adapter integration and unit tests, not a production migration or proof of end-to-end deployment.


## Planned key renewal and emergency revocation

The original registry has one active key per role and immediate rotation rejects the old application configuration. The optional rotation candidate adds a previous key and expiry, retaining the existing verifier permissions. Use an explicit, short overlap (for example ten minutes), atomically copy the current key into previous_secret and set the new random key plus previous_valid_until, then update the protected application environment and verify actual login/read/write operations. Clear both previous fields after verification. If a key is suspected compromised, skip overlap and immediately revoke it; availability does not supersede security. Never log either key, store keys in Git, or export them to unencrypted backups. A restored signing registry and app secret configuration must be synchronized, or fresh keys provisioned, before enabling signed mode. Test restart, key recovery and rollback before production. The staged overlap proof covers six controls; this candidate does not authorize live changes.
