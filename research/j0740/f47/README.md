# F47 — Source-locked seven-model *common-mass-window* conditional integrals

Calculates real observational likelihood at seven directly computed fixed-spin RNS curves **only after F46 all 7 numerical root matrices pass**. Inputs are F38 published-sample reconstructed posterior/source-effective-prior KDE arrays (all six surfaces), plus separately pinned F44 original C/GR anchors and all SHA-crosslinked F46 mass sequences. The same 1.95–2.10 M_sun window is applied for **every** model, with one common Gaussian radio-mass prior N(2.082,0.0703^2) truncated +/-5 sigma. The observational posterior/prior division is already done in F38 and is not applied again.

Reports two different quantities per EOS and per bandwidth: (a) the *contribution* of this common mass window to the full radio-prior integral, and (b) its *conditional* common-window score. It also reports an illustrative equal-hypothesis-model-prior normalization restricted to this window, which is **NOT a physically justified EOS posterior**. The omitted tail contribution is unknown, never assigned zero. KDE-bandwidth sensitivity and Simpson-vs-trapezoid differences are retained.

Original nuclear EOS are **not** these F42 causal-lift+cold-gas constructions (notably WFF1/WFF2 source curves required large modifications). No global fixed-J dynamical stability, physics-motivated seven-model prior, X-PSI photon-level refit, or final seven-EOS Bayesian evidence is claimed. The CI fails closed when any F46 curve is absent, unstable/unsolved, or falls outside the published F38 support mask. No extrapolation in mass/radius. This is an explicit reproducible conditional experiment, not a discovery of the neutron-star core microphysics.
